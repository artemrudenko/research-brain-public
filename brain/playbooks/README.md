# playbooks/ — reusable methods

Step-by-step procedures you re-run. A playbook captures *how* to do something repeatable —
a research routine, a triage method, a digest-assembly checklist — so the method itself
becomes durable knowledge.

**What goes here**
- A method with multiple steps that you expect to follow more than once.
- Written as numbered steps or a checklist, with inputs, outputs, and gotchas.
- Link related concepts with `[[wikilinks]]` so the playbook shows up in the graph.

**What does NOT go here**
- A definition or synthesized answer → that's a **concept** (`concepts/`).
- A one-off fact from a single source → that's a **lesson** (`lessons/`).

Reference a playbook from a concept's **Related notes** section when the concept is best
*applied* via that method.
