# lessons/ — atomic facts & watchlists

Small, single-fact extracts pulled from individual sources during triage. A lesson is for
knowledge that is worth keeping but isn't (yet) a full concept — a notable statistic, a
caveat, a thing to watch.

**What goes here**
- One source → up to ~5 atomic facts in a single note.
- Each note must link to a concept or playbook (`related_concept:` / `parent_playbook:` in
  frontmatter) so it stays connected in the graph — no orphans.
- Use `lesson-template.md` (in `brain/`) as the starting point.

**What does NOT go here**
- A fully synthesized, multi-source answer → that's a **concept** (`concepts/`).
- A repeatable method → that's a **playbook** (`playbooks/`).

A lesson is typically either **promoted** into a concept once enough related facts
accumulate, or kept as a standing fact that a concept links to.
