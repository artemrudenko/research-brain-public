> Подробности: [README.md](README.md) · [QUICKSTART.md](QUICKSTART.md) ·
> [USER_GUIDE.md](USER_GUIDE.md) · [FIRST-RUN.md](FIRST-RUN.md).

## Что это

**research-brain** — персональный исследовательский ассистент: он следит за выбранными вами
темами и источниками (RSS, блоги, поисковые платформы), превращает найденное в базу знаний
(`brain/` — Obsidian-совместимый vault) и присылает еженедельный дайджест в email, Telegram
или Rocket.Chat. Вы управляете им обычными словами через **Cowork / Claude Code** — терминал
и навыки программирования не обязательны. Рекомендуемый путь — **full agentic** setup;
**RSS Digest Lite** и headless-транспорты — advanced fallback, когда агентный runtime
недоступен.

## Что нужно

- **Cowork или Claude Code** — ассистент, который всё выполняет за вас:
  [claude.com/product/claude-code](https://www.claude.com/product/claude-code).
- **Python 3.11+** — на большинстве Mac и Linux уже есть; ассистент сам запустит установщик.
- **Опционально:** [Obsidian](https://obsidian.md) ≥1.7 — просматривать базу знаний как блокнот.

## Кратчайший путь (без терминала)

Четыре шага: распаковать архив, открыть папку в ассистенте — и дальше просто
*говорить* с ним. Терминал и командная строка не нужны; пароли в файлы не попадают.
(Предпочитаете командную строку или cron без агента? — см.
[приложение «Продвинутый путь»](#продвинутый-путь-терминал-и-cron) внизу.)

1. **Распакуйте** присланный архив и **откройте папку** в Cowork / Claude Code
   (*File → Open folder*). Скажите ассистенту *«установи и настрой этот проект»* —
   он сам поставит зависимости и запустит мастер настройки.

2. **Настройте источники.** Скажите ассистенту:

   > **давай настроим источники** (или *«let's set up sources»*)

   Мастер `setup-wizard` спросит темы, источники, каналы доставки, расписание, язык
   дайджеста и уровень подачи — и запишет весь конфиг за вас. Секреты в файлы не
   попадают: Gmail подключается в ассистенте одним кликом, токен Telegram-бота хранит
   настройка плагина (`telegram:configure`).

3. **Проверка активации.** Мастер делает это сам в конце настройки — ничего не
   отправляя. Он показывает поля `Source:`, `Config:`, `Delivery:`, `Schedule:`,
   `First value:`, `Next action:`. Если всё готово, но расписание ещё не
   зарегистрировано, статус будет `ready_schedule_not_registered`: нужно
   `register one recurring run` для `schedule/weekly-run.md`.

4. **Первый прогон.** Скажите:

   > **run the pipeline now**

   Это `run-now`: сбор → санитайз (анти-инъекционный гейт) → курирование → синтез →
   гигиена brain → дайджест → доставка, каждый шаг ждёт завершения предыдущего.
   Дайджест придёт во включённые каналы.

   Для автоматического еженедельного запуска зарегистрируйте один recurring run для
   `schedule/weekly-run.md`; запись в `config/schedule.yaml` — это только расписание, не
   регистрация scheduler. Для быстрого «что нового?» без полного прогона есть команда `/new` в Telegram (или
   просто спросите «что нового?») — ответ приходит прямо в чат, без файлов и рассылки.

## Telegram: важная мелочь

Команды `/digest`, `/run`, `/save` и т.п. работают, когда сессия запущена с живым
Telegram-каналом. Но `/help`, `/status` и `/start` перехватывает сам плагин Telegram —
до проекта они не доходят. Пишите эти два слова **без слэша**: просто `help` или `status`.
Полный список команд и настройка бота: [docs/telegram-commands.md](docs/telegram-commands.md)
и [QUICKSTART.md](QUICKSTART.md) (на английском).

## Продвинутый путь: терминал и cron

Нужен, только если вы хотите работать из командной строки или запускать систему
headless/cron без агента. Большинству пользователей это не понадобится. Учтите:
терминальный конфигуратор задаёт вопросы **по-английски**.

1. **Зависимости** — в терминале в папке проекта:

   ```bash
   make install    # ставит uv + venv + зависимости; ничего не настраивает
   ```

2. **Конфигурация** — интерактивное интервью в терминале (EN):

   ```bash
   ./install.sh --configure   # или: make configure
   ```

3. **Секреты (только для headless/cron и Rocket.Chat).** Файл нужен только для
   Rocket.Chat и headless/cron-транспортов (`smtp` / `bot-api`); на пути через
   ассистента пароли в файлы не попадают:

   ```bash
   cp config/.env.example config/.env   # затем впишите нужные ключи
   ```

4. **Проверка активации вручную** — в любой момент (ничего не отправляет):

   ```bash
   python3 scripts/setup_check.py
   ```

Расписание (cron), выбор транспортов и headless-доставка — в
[docs/scheduling.md](docs/scheduling.md) и в разделе Advanced файла
[QUICKSTART.md](QUICKSTART.md).
